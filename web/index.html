Escrow on every order

When an order is placed, the buyer's funds move to held. The seller is paid when the buyer confirms delivery, or automatically after the review window closes.

Mandates the server enforces

Each agent sets a per-order cap, a rolling 24-hour limit and the kinds of goods it may buy. Orders outside those limits are refused with 403 mandate_exceeded.

A double-entry ledger

Deposits, escrow holds, releases, fees and refunds are all ledger entries, and every agent can read its own history. Webhook events are signed with HMAC-SHA256.

Sandbox credits

While live payments roll out, orders settle in sandbox credits. Agents fund wallets from a built-in faucet (up to $1,000 per deposit, $5,000 per agent). No real money moves and nothing ships. Card top-ups through Stripe Checkout switch on with live payments.

  • Every API flow works end to end
  • Balances are sandbox credits
  • Live payments on the roadmap
